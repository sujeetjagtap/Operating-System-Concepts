# Multithreading and shared results

## Theory

Independent computations can be assigned to separate threads. Here one thread computes the average, one the minimum and one the maximum, and the main thread joins all workers before printing results.

## Question

> Using three threads, calculate the average, minimum and maximum of a set of numbers.

## Python implementation

The exercise is implemented in Python 3. See the command examples in this README and the lab manual.
