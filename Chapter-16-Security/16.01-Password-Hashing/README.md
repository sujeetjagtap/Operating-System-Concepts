## Theory

## Practical Question

> Demonstrate secure password storage using salted password hashes and verify passwords without storing plaintext.

## Suggested Tasks

1. Read the relevant textbook concept before running the program.

3. Extend the starter implementation into a complete simulation.
4. Test at least three different input/workload scenarios.
