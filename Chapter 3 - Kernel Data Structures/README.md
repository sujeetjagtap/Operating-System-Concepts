# Kernel linked lists and data structures

## Theory

Linux kernel linked lists embed list metadata in data structures and support insertion, traversal and deletion without requiring a separate container object. The Python versions model the same ideas with ordinary classes and linked nodes because Python code runs in user space.

## Question

> Use a kernel-style linked list to store and traverse a Collatz sequence and a list of RGB color records.
