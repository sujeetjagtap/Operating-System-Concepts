# Disk Access Time Simulation

## Chapter

**Chapter — 11 Mass-Storage-Structure**

## Objective

This recommended Python laboratory provides a feasible **user-space simulation or practical demonstration** of the operating-system concept associated with this topic.

## Theory

This exercise is designed to reinforce the relevant operating-system concept through a Python implementation. The implementation should model the important state transitions, resource decisions, scheduling/allocation behavior, or protection mechanisms described by the concept, while avoiding the claim that Python is replacing kernel-level functionality.

## Practical Question

> Estimate disk access time from seek, rotational latency, and transfer-time components.

## Suggested Tasks

1. Read the relevant textbook concept before running the program.
2. Execute the supplied Python program.
3. Extend the starter implementation into a complete simulation.
4. Test at least three different input/workload scenarios.
5. Record observations and explain how the results relate to the OS concept.
6. Discuss assumptions, limitations, and real-system differences.

## Python Implementation

- **Language:** Python 3.10+
- **Dependencies:** Python standard library unless otherwise stated.
- **Program:** `11.02_disk_access_time.py`

Run from the repository root:

```bash
python Recommended-Python-Labs/Chapter-11-Mass-Storage-Structure/11.02-Disk-Access-Time/11.02_disk_access_time.py
```

## Expected Learning Outcome

After completing the lab, the student should be able to explain the underlying OS mechanism and demonstrate it using a reproducible Python model.
