# Bidirectional inter-process communication

## Theory

Two ordinary pipes provide two-way communication: parent-to-child for the original message and child-to-parent for the transformed message. The child reverses the case of alphabetic characters.

## Question

> Use two ordinary pipes for parent-child communication so the child reverses the case of a message and sends the altered message back.

## Python implementation

The exercise is implemented in Python 3. See the command examples in this README and the lab manual.
