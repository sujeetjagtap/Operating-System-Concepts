# Environment Setup Quick Reference

The repository requires Python 3.10+.

- Linux/macOS/BSD: `./setup.sh`
- Windows PowerShell: `./setup.ps1`
- Windows Command Prompt: `setup.bat`

All core exercises use the Python standard library. See the root `README.md`
for detailed installation instructions for Debian-based Linux, Red Hat/Fedora,
BSD, Windows, and macOS, plus Linux `/proc` portability notes.
