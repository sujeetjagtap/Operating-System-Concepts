# Monte Carlo computation and threads

## Theory

Monte Carlo estimation of π samples random points in a unit square. The fraction falling inside the quarter-circle approximates π/4, so π ≈ 4 × inside/total. The computation runs in a worker thread.

## Question

> Use a worker thread and the Monte Carlo method to approximate the value of π.
