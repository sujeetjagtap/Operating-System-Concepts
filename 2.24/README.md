# Low-level file I/O

## Theory

File descriptors provide a low-level interface to files. The exercise uses open/read/write/close to copy bytes from a source file to a destination file, illustrating system calls and file metadata.

## Question

> Write a program that copies the contents of one file to another using low-level file operations.

## Python implementation

The exercise is implemented in Python 3. See the command examples in this README and the lab manual.
